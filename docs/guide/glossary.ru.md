# Русский глоссарий интерфейса LoopLab

Правила для русского каталога `ui/src/locales/ru.json` и встроенных русских строк. Каталог
раньше был сырым машинным переводом («Назад к бегу», «наружный жгут», «код раствора»);
стоп-лист `ui/test/russianCatalogueQuality.test.js` не даёт этим формам вернуться.

## Термины

| Термин (EN) | Перевод | Не использовать |
|---|---|---|
| run | **запуск** | бег, забег, пробег, процесс |
| champion / best | **лучший результат** | чемпион |
| concept | **концепт** | концепция, понятие |
| claim | **утверждение** | претензия |
| evidence | **доказательства** | улики |
| refresh | **обновить** | освежить |
| harness / external agent | **внешний агент** | жгут, упряжь |
| assistant | **ассистент** | — |
| report | **отчёт** | доклад |
| token | **токен** | символ |
| solution | **решение** | раствор |
| trial | **прогон** | судебный процесс |
| seed | **seed** | семя, семечко |
| fork | **ответвление** | вилка |
| generation (of a run) | **версия запуска** | поколение |
| experiment / node | **эксперимент** | узел (в тексте для человека) |
| research question | **исследовательский вопрос** | — |
| memo | **записка** | — |
| Agent obligations | **обязательства агента** | цикл агента |

## Правила

- Обращение на «вы», повелительное наклонение в кнопках: «Открыть», «Повторить», «Сохранить».
- Идентификаторы, ключи схем, команды, пути, имена метрик и событий не переводятся и остаются
  латиницей (`inject_node`, `report_generated`, `InCart_FilteredUnseenRecall@200`). В прозе их
  лучше брать в обратные кавычки.
- Названия продуктов не переводятся: Codex, Claude Code, LoopLab, MLflow.
- `#{0}` остаётся `#{0}` (не «No {0}»); стрелки `→`, `›`, `←` сохраняются; плейсхолдеры `{0}`,
  `{1}` — те же, что в ключе.
- CSS-классы и списки идентификаторов, которые сборщик каталога подхватил как текст, переводятся
  тождественно (значение равно ключу).
- Пробелы между словами обязательны. Текст без пробелов («Следомc5w01оттогожеbase») не
  исправляется автоматически: эвристика может испортить идентификаторы. Внешний агент получает
  предупреждение `readability` в квитанции команды.
- Фраза собирается целиком: склейка `'…' + '…'` не находит запись в каталоге и показывается
  по-английски.
