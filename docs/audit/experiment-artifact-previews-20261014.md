# Протокол приёмки: предпросмотр файлов эксперимента

Источник требований: [doc 77, раздел 3](../77-experiment-tracking-open-items-2026-10-13.md#3-предпросмотр-файлов--p1). Результат приёмки ещё не получен.

1. Открыть «Файлы» на завершённом ране MiniOneRec после выкладки сборки с этим изменением.
2. Выбрать «эксперимент #N»: в списке только `nodes/node_N/…`; у корня, где файлов больше страницы, работает «Загрузить ещё файлы» и не теряет и не повторяет файлы.
3. Проверить реальные график (PNG), CSV, JSON, PDF и checkpoint (`.safetensors`): у каждого подходящее представление или честные метаданные; SVG/HTML не исполняются.
4. В Inspector → «Код» → «Унаследованная база» открыть JSON/CSV и переключить «Форматированный».
5. Итог записать датированной строкой RESULT с проверенным раном, commit UI и остатком.
