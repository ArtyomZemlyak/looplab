# Протокол приёмки: ресурсы попытки

Источник требований: [doc 77, раздел 4](../77-experiment-tracking-open-items-2026-10-13.md#4-p2). Результат приёмки ещё не получен.

1. Взять завершённую 8-GPU попытку MiniOneRec, для которой у оператора есть `resources.json`/`resources.csv`.
2. Открыть Inspector → Overview → «Ресурсы этой попытки» и сверить: число GPU, время стадий `train`/`score`, GPU·ч (GPU × сумма стадий ÷ 3600), шаги/с (max_steps ÷ время обучения) — с файлами оператора.
3. Убедиться, что строки предыдущего жизненного цикла (до `node_reset`) не входят во время, а скорость, которую сообщил тренер, показана в его единицах (tree rows/s не переименованы в примеры/с).
4. Отсутствующая пиковая память показана как «не записано».
5. Итог записать датированной строкой RESULT с проверенной попыткой, commit UI и остатком.
