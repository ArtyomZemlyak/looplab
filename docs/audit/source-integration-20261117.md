## What changed

- Completed evaluators settle advisory observations without holding terminal completion for an
  answer. Explicit kill/abort and dishonest or unknown results retain their own lifecycle guards.
- Pending inject cancellation, metadata preflight for saved vectors, paged/bounded research reads,
  authored work intents/checkpoints and operator-direction retirement expose native recoverable
  state. Notification delivery remains distinct from execution and explicit addressed ACK.
- Job-role materialization, repair-slot accounting, staged atomic raw publication, metric behavior
  diagnostics, report/premise review and source-derived skills have meaningful CPU acceptance.
- Optional Best-of-N pilots execute inside one normally admitted native attempt; the CPU stdio
  worker uses immutable invocation identity and exact retry. Both default to disabled, and neither
  CPU fixtures nor null defaults establish GPU, cross-host, Windows or utility acceptance.
- UI report review follows the explicit API barrel and one-way dependency contract. The retired
  structured-claims toggle stays absent, with legacy input compatibility. Calibration tests pin
  both the historical retirement-only envelope and the wider current schema; guards are unchanged.
