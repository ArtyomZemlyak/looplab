# Протокол приёмки: композиция отчёта внешнего агента

Источник требований: [doc 76, раздел 5](../76-external-agent-ux-open-items-2026-10-13.md#5-llm-p2). Результат полной приёмки ещё не получен.

1. Проверить текущий, завершённый и устаревший отчёт на desktop/mobile; сохранить снимки и commit UI.
2. Главный результат, четыре метрики, основание сравнения, ограничения, артефакты и следующие действия должны быть доступны без JSON.
3. Сверить все числа с измеренными результатами; интерпретацию модели не выдавать за измерение. Проверить freshness/coverage и отсутствующие поля.
4. Проверить длинный текст, таблицы и ссылки. External harness публикует отчёт без второй обязательной модели; дополнительная внутренняя генерация сохраняет явное платное действие и receipts.
5. Итог записать датированной строкой RESULT с проверенными сценариями, снимками и остатком. Частичная проверка не закрывает всю приёмку.
