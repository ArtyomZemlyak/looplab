# Bench-box task files

Task files of real runs on the maintainers' bench box (a JupyterHub server with H200/L40S GPUs and
data under `/home/jovyan/data`). They are kept as the record those runs were launched from and are
cited by tests and design documents; they will not run elsewhere, because every path in them names
that machine. The operator runbook for launching the next round is [`../NEXT_RUN.md`](../NEXT_RUN.md).

For runnable examples, see [`examples/`](../../examples/README.md).
